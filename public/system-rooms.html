System Rooms
Gestión Hotelera Inteligente

Sistema PMS (Property Management System) para la gestión completa de hoteles: control de habitaciones en tiempo real, check-in/check-out, caja diaria y reservas. Arquitectura de tres capas contenerizada con Docker.

Ver repositorio Consultar por el proyecto
Descripción

¿Qué es System Rooms?

Es un sistema que centraliza la operación diaria de un hotel en una sola aplicación web, reemplazando planillas y libretas por un sistema que refleja el estado real de cada habitación y automatiza los flujos de recepción.

Estado en tiempo real

Visualización del estado de cada habitación: LIBRE, OCUPADA o SUCIA.

Check-in / Check-out

Flujos completos con validaciones, cobro de depósito y generación de cuenta.

Caja diaria

Apertura y cierre de turno, con comparación de monto esperado vs. contado.

Validaciones

Previene errores: no permite check-in en habitación ocupada o sucia.

Huéspedes y reservas

Gestión de huéspedes, reservas previas y walk-ins.

Auditoría de movimientos

Registro de cada movimiento de dinero para trazabilidad completa.

Stack

Tecnologías utilizadas

Backend — Django + DRF

API REST construida con Django REST Framework, autenticación JWT con SimpleJWT y documentación interactiva con drf-spectacular (Swagger/OpenAPI).

Frontend — React + TypeScript

Interfaz SPA con Vite, React y TypeScript. Estilos con Tailwind CSS, servida por Nginx en producción.

Base de Datos — PostgreSQL 15

Almacenamiento relacional con volumen persistente. Administración visual con pgAdmin 4.

Infraestructura — Docker Compose

Orquestación de todos los servicios: frontend, backend, base de datos y pgAdmin en una sola red interna.

Arquitectura de tres capas

Cada capa corre en su propio contenedor, comunicada por HTTP/JSON entre frontend y backend, y por TCP entre backend y base de datos.

Flujo

Cómo funciona el sistema

1. Apertura de caja

El recepcionista inicia su jornada abriendo el turno de caja.

2. Grid de habitaciones

Vista principal con el estado de todas las habitaciones del hotel en tiempo real.

3. Check-in (azul)

Buscar reserva o crear walk-in, elegir habitación LIBRE y LIMPIA, cobrar depósito y cambiar a OCUPADA.

4. Check-out (rojo)

Ver cuenta con cargos y pagos, cobrar saldo pendiente y cambiar estado a SUCIA.

5. Marcar limpia (verde)

Recepción o limpieza confirma el aseo, la habitación vuelve a LIBRE en el grid.

6. Cierre de turno

Comparación del monto esperado vs. el monto contado al final de la jornada.

Roadmap

Completado

  • Base de datos PostgreSQL con volumen persistente
  • Backend Django + DRF con autenticación JWT
  • Modelo de habitaciones (LIBRE / OCUPADA / SUCIA)
  • Endpoint /marcar-limpia/
  • Frontend Vite + TypeScript con grid
  • Integración Frontend ↔ Backend
  • Swagger UI para la API
  • pgAdmin pre-configurado

En desarrollo

  • Flujo completo de Check-in
  • Check-out con generación de cuenta
  • Gestión de caja (apertura / cierre)
  • Login en frontend con JWT
  • Modelo de huéspedes y reservas

Futuro

  • Reportes y estadísticas
  • Notificaciones en tiempo real (WebSockets)
  • Tests automatizados (pytest + vitest)
  • Despliegue en producción
