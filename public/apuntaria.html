ApuntarIA - Plataforma Inteligente de Estudio con Inteligencia Artificial

Plataforma web diseñada para transformar clases, documentos y material educativo en recursos de estudio interactivos mediante Inteligencia Artificial, permitiendo resumir contenido, generar material de aprendizaje y responder consultas sobre cualquier tema procesado.

🎙️ Grabación de Clases

Permite grabar clases o conferencias directamente desde la plataforma para su posterior procesamiento, transcripción y análisis automático mediante IA.

📂 Carga de Archivos

Soporta la carga de archivos PDF, audios y videos para convertir cualquier material de estudio en contenido estructurado y fácil de comprender.

▶️ Procesamiento de Videos de YouTube

Analiza videos educativos mediante un enlace de YouTube, extrayendo el contenido para generar apuntes, resúmenes y recursos de aprendizaje automáticamente.

📝 Resúmenes Inteligentes

La Inteligencia Artificial identifica los conceptos más importantes y genera resúmenes claros, organizados y optimizados para estudiar de forma eficiente.

🧠 Cuadros Sinópticos y Mapas Conceptuales

Organiza automáticamente la información en estructuras visuales que facilitan la comprensión de relaciones entre conceptos y temas principales.

❓ Evaluaciones Automáticas

Genera preguntas de práctica, ejercicios y simulaciones de examen con respuestas explicadas para reforzar el aprendizaje del estudiante.

💬 Asistente Conversacional

Permite interactuar mediante un chat inteligente que responde preguntas utilizando exclusivamente el contenido procesado de cada clase, documento o video.

🎴 Flashcards y Material de Estudio

Crea automáticamente tarjetas de estudio, conceptos clave y recursos personalizados para facilitar la memorización y la preparación de exámenes.

Tecnologías Utilizadas

Python · FastAPI · OpenAI API · Whisper · PostgreSQL · HTML · CSS · Bootstrap · JavaScript · Procesamiento de Audio · Procesamiento de PDF · Inteligencia Artificial Generativa

ApuntarIA fue concebido como un asistente de estudio inteligente capaz de transformar cualquier clase, documento o recurso educativo en resúmenes, cuadros sinópticos, mapas conceptuales, flashcards, evaluaciones y un tutor virtual disponible las 24 horas, optimizando significativamente el proceso de aprendizaje.
