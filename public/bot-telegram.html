PediteUNO - Plataforma Inteligente para Transporte Urbano

Sistema desarrollado en Python y Telegram para la gestión automatizada de solicitudes de viajes, validación de conductores y administración centralizada de servicios de transporte.

🚖 Solicitud Automática de Viajes

Los pasajeros pueden solicitar viajes enviando su ubicación en Telegram. El sistema calcula automáticamente la tarifa y distribuye el viaje a la red de conductores disponibles.

📍 Geolocalización Inteligente

Procesamiento de ubicaciones en tiempo real para determinar cobertura, calcular distancias y optimizar la asignación de viajes.

📄 Validación de Conductores

Registro automatizado mediante carga de DNI, licencia de conducir, habilitación vehicular y documentación requerida para operar.

⚙️ Panel Administrativo

Centro de control para aprobar conductores, supervisar operaciones, gestionar incidencias y monitorear toda la actividad de la plataforma.

💰 Motor de Tarifas Dinámicas

Cálculo automático basado en distancia, horarios diurnos/nocturnos y parámetros configurables adaptables a cada ciudad.

🛡️ Sistema Anti-Fraude

Detección de cancelaciones recurrentes, bloqueos automáticos y registro histórico para auditoría y seguridad operativa.

Tecnologías Utilizadas

Python · Telegram Bot API · SQLite · Excel Automation · Geolocalización · Automatización de Procesos · Generación de Reportes

PediteUNO fue diseñado como una solución escalable para modernizar servicios de taxis y remises, automatizando completamente la gestión de pasajeros, conductores y operaciones comerciales.
